# 01. 기획서

## 1. 한 줄 정의

지금 이 순간 태어나는 아기 중 한 명이 되어, 실제 통계가 만드는 확률 속에서 한 사람의 일생을 0세부터 죽음까지 살아보는 인생 시뮬레이션. 한 번의 삶은 약 30분~1시간 30분.

## 2. 타깃

| 구분 | 설명 | 핵심 욕구 |
|---|---|---|
| 주 타깃 | 20~30대, 사회·세계 이슈와 감성 콘텐츠에 관심 있는 웹 사용자 | "내가 다른 곳에서 태어났다면?" 이라는 호기심, 공유할 만한 경험 |
| 2차 타깃 | 교사·학생(세계시민교육, 사회 과목) | 수업에서 쓸 수 있는 안전한 체험형 교재 |
| 3차 타깃 | 해외 사용자(다국어 확장 후) | 동일 |

## 3. 핵심 루프

```
[출생 추첨] → [출생 신고서 공개] → ┌ 1년 경과(자동 진행) ──────────┐ → [사망] → [인생 기록·자서전] → [공유 / 다시 태어나기]
                                   │  ├ 올해의 초점 선택             │
                                   │  ├ 무작위 사건 발생             │
                                   │  ├ 갈림길 결정(일시정지)        │
                                   │  └ AI 서사 한 줄 + 장면 갱신     │
                                   └──────────── 반복 ──────────────┘
```

- **한 해 = 약 40~90초.** 인생 길이 설정(30분/1시간/1.5시간)과 그 나라 기대수명으로 계산한다.
- **갈림길(결정)** 이 오면 시간이 멈춘다. 자동 결정 모드에서는 성향에 맞게 자동 선택한다.
- **이정표 나이**(예: 6·15·20·30·45·60·75세)에는 성찰 질문과 연출 장면이 나온다.

## 4. 화면 구성

| # | 화면 | 주요 요소 |
|---|---|---|
| S1 | 첫 화면 | 실시간 출생/사망 카운터, 출생 확률 상위 국가, 세계 지도, 옵션(시대·추첨 기준·인생 길이·실제 출생국), 태어나기 버튼, 이어하기 |
| S2 | 출생 추첨 | 국가 룰렛 연출 → 지도 줌인 → 출생 신고서(이름, 날짜, 장소, 부모, 형편, 이 나라에 태어날 확률) |
| S3 | 인생 화면 | 상단: 나이·연도·속도 조절. 좌: 신분 카드·상태값·돈·가족. 중앙: **장면 일러스트**·AI 서사·초점 선택·인생 기록. 우: 동시 출생자 4명, 인생 지도(1칸=1년), 생존 곡선, 국가 통계 |
| S4 | 갈림길 모달 | 상황 설명(AI 서술), 선택지 2~4개, 선택지별 힌트(비용·조건), 통계 근거 보기 |
| S5 | 사망 기록 | 사망 원인·나이, 같은 해 태어난 사람 대비 위치, 인생 연표, **AI 자서전**, 남긴 한마디, 공유 카드 |
| S6 | 전생 기록 | 지금까지 산 삶 목록, 국가 수집 현황, 통계(평균 수명 등) |
| S7 | 국가 통계 | 국가별 지표와 출처 (SEO 페이지 겸용) |

## 5. 기능 범위

### MVP (첫 공개)
- 출생 추첨(출생아 수 기준), 출생 신고서
- 상태값 4종(건강·행복·지식·관계) + 돈/소득
- 올해의 초점 6~8종
- 생애 이벤트 묶음: 영유아 건강, 학교·진학, 첫 직업, 연애·결혼·출산, 질병, 은퇴, 부모의 죽음
- 직업 40종 이상
- 생명표 기반 사망, 사망 원인 추첨
- 속도 조절·일시정지·자동 결정, 로컬 저장·이어하기
- 사망 기록 + AI 자서전(짧은 버전) + 공유 이미지
- 장면 일러스트 v1 (생애 단계 × 지역 × 도시/농촌 조합)
- 한국어

### v1
- 동시 출생자 4명 병행 시뮬레이션
- 이주·난민, 군복무, 사업, 투자·주택
- 연간 AI 서사, 이정표 성찰 질문, 마지막 편지
- 직업 120종 이상, 갈림길 300개 이상
- 시대 모드(과거 1950~2025 / 미래 전망)
- 계정·클라우드 저장, 영어

### v2
- 친구와 같은 1초에 태어나기(공유 시드 멀티플레이)
- 추모관·커뮤니티, 교육 모드·교사용 대시보드
- 다국어 확장, 사운드·음악 시스템

## 6. 수익 모델 (원칙: 삶의 결과에 영향을 주는 판매 금지)

| 후보 | 설명 | 비고 |
|---|---|---|
| 기념품 패스 | 끝난 삶으로 AI 장편 자서전, 인쇄용 기록집, 영상 생성 | AI 비용과 연동되는 프리미엄 |
| 후원/구독 | 무제한 AI 서사 품질 상향, 클라우드 보관 무제한 | 무료로도 핵심 경험은 완결 |
| 교육 라이선스 | 학교·기관용 교사 대시보드 | v2 |
| 광고 | 기본 미적용 (경험 훼손) | 보류 |

## 7. 안전·연령

- 15세 이상 권장. "무서운 장면 빼기" 옵션과 교육 모드 제공.
- 자살·폭력·성폭력·약물 이벤트는 장면 묘사 없이 사실만 알리고, 플레이어 국가 기준 상담처를 안내.
- 사용자 입력(한마디, 게시글)에 위기 신호 감지 시 상담처 안내.
- AI 출력에 안전 필터 적용 ([04-ai-narrative.md](04-ai-narrative.md) 참고).
