# 02. 시뮬레이션 모델

엔진은 UI와 분리된 순수 TypeScript 모듈이다. 같은 시드와 같은 입력(선택)이면 같은 삶이 재현된다.

## 1. 설계 원칙

- **결정적(deterministic):** 모든 난수는 시드 기반 PRNG(예: xoshiro128**)에서 나온다. 저장은 `seed + 선택 로그`만으로도 복원 가능하다.
- **통계 앵커:** 모든 확률은 "통계 기준값"에서 출발해 개인 요인으로 보정한다. 보정은 오즈비(odds ratio)로 하고, 인구 평균에서 보정 배수의 기댓값이 1이 되도록 정규화한다.
- **검증 가능:** 엔진만 떼어 10만 명을 돌려 기대수명·영아사망률·대학 진학률 등이 원천 통계와 오차 범위 안에 드는지 테스트한다.

## 2. 상태 (Person State)

```ts
interface Person {
  seed: string;
  era: { mode: 'now' | 'past' | 'future'; birthYear: number };
  born: { country: ISO3; region: RegionCode; urban: boolean; date: string };
  sex: 'F' | 'M';
  name: { given: string; family?: string };
  household: 1 | 2 | 3 | 4 | 5;          // 출생 가정 형편 분위(1=최하)
  traits: Record<TraitId, number>;        // 숨은 재능·성향 0~1 (학업, 운동, 예술, 사교, 위험선호…)

  age: number;                            // 만 나이
  t: number;                              // 연 단위 연속 시간 (예: 23.4)
  stats: { health: number; happiness: number; knowledge: number; relations: number }; // 0~100
  money: { cash: number; debt: number; assets: Asset[]; income: number; incomePct: number }; // PPP 달러
  edu: { level: EduLevel; inSchool?: SchoolState; major?: MajorId };
  career: { job: JobId | null; years: number; formal: boolean; history: CareerRecord[] };
  location: { country: ISO3; urban: boolean; migrant?: MigrationState };
  family: Family;                         // 부모, 형제, 파트너, 자녀 (각자 나이·생존·관계도)
  health: { conditions: Record<ConditionId, Condition>; habits: Habits };
  focus: FocusId | null;
  flags: Record<string, number | boolean | string>; // 이벤트 DSL이 읽고 쓰는 범용 플래그
  history: YearRecord[];                  // 연도별 스냅샷 (차트·인생 지도·AI 입력)
  log: LogEntry[];                        // 인생 기록 문장(키+파라미터)
  pending: Decision | null;               // 대기 중인 갈림길
  dead?: { age: number; cause: CauseId; year: number };
}
```

## 4. 연간 진행 (Tick)

실시간 진행은 `yearSec = 인생길이(초) / max(기대수명, 60)` 로 1년의 길이를 정한다(하한·상한 존재). 한 해 안에서 사건은 `at`(0~1, 연중 시점)에 배치된다.

한 해가 끝날 때(혹은 연중 사건 시점마다) 아래 순서로 처리한다.

1. **나이 증가**와 생애 단계 전환(영유아 → 아동 → 청소년 → 청년 → 중년 → 노년)
2. **초점 효과:** 올해 초점에 머문 시간 비율만큼 상태값 변화
3. **수동 변화:** 노화에 따른 건강 감소, 소득·지출·저축·부채 이자, 가족 구성원 나이 증가와 그들의 사망 판정
4. **예약 사건:** 이전 결정이 예약한 사건 실행(예: 3년 뒤 졸업)
5. **무작위 사건 추첨:** DSL 이벤트 풀에서 조건을 만족하는 사건을 가중치로 추첨 (연 최대 N개, 쿨다운 적용)
6. **갈림길:** 발생 시 시간 정지 → 선택 → 결과 적용
7. **사망 판정:** 아래 5절
8. **스냅샷:** `YearRecord` 저장 → 차트·인생 지도 갱신 → AI 서사 요청(비동기, 실패 시 템플릿 문장)

## 5. 확률 보정 규칙

모든 사건 확률은 다음 형태로 계산한다.

```
p_base   = 통계 기준값 (국가·연령·성별)
odds     = p_base / (1 - p_base)
odds'    = odds × Π(개인 요인 오즈비) / 정규화상수
p        = odds' / (1 + odds')
```

- 개인 요인 예: 형편 분위, 상태값(건강·지식…), 습관(흡연·음주), 선택 결과, 성향.
- **정규화상수**는 엔진 빌드 시 몬테카를로로 계산해, 인구 전체 평균 확률이 `p_base` 와 같도록 맞춘다. 이렇게 하면 개인 요인을 아무리 추가해도 국가 통계가 깨지지 않는다.
- 연속값 요인(상태값 등)은 `exp(β × (x − 기준값))` 형태의 오즈비를 쓴다.

## 6. 사망 모델

- **기준:** 국가·성별·연령별 사망확률 `q(x)` (UN WPP 단일 연령 생명표). 과거 모드는 해당 연도 생명표, 미래 모드는 전망 생명표.
- **개인 배수:** 건강 상태값, 소득 분위, 흡연·음주·약물, 만성질환과 치료 여부, 분쟁 지역 거주, 사회적 고립 등. 5절의 오즈 보정 방식으로 적용하고 배수는 [0.25, 9] 로 제한.
- **고령 수렴:** 85세 이후 개인 배수의 효과를 점차 줄여 초고령 생존율이 비현실적으로 늘지 않게 한다.
- **사망 원인:** 지역 × 연령대 × 성별 사망 원인 분포에서 추첨하되, 보유 질환·습관·직업 위험이 해당 원인의 가중치를 높인다.
- **검증:** 국가별로 기대수명(e0), 5세 미만 사망률을 시뮬레이션 결과와 비교하는 회귀 테스트.

## 6.1 보정 (구현됨)

정규화상수는 `scripts/calibrate.ts`가 국가별 몬테카를로로 구해 `data/build/calibration.json`에 저장한다.

- **사망:** 국가·성별·연령대(0, 1–4, 5–14, 15–29, 30–44, 45–59, 60–74, 75–84, 85+)마다 개인 배수의 평균을 구해 나눈다.
- **결혼:** 동반자를 만날 연간 확률 = 1 − exp(−k · (−ln(1 − 결혼경험비율)) · g(나이)). g는 평균 초혼 연령 근처의 정규분포 모양. k를 보정해 45~49세 결혼 경험 비율(UN World Marriage Data)을 맞춘다.
- **출산:** 동반자가 있는 여성(또는 남성의 여성 동반자)의 연간 출산 확률 = 연령별 출산율(WPP) × f. f를 보정해 합계출산율을 맞춘다.
- 세 계수는 서로 영향을 주므로 4회 반복해서 함께 맞추고, 보정에 쓰지 않은 시드로 검증한다.

## 6.2 국제 이주 (구현됨)

- **노동 이주:** 출생국에 사는 18~50세에게 해마다 "해외로 일하러 갈 기회" 갈림길이 온다. 확률은 출생자 중 해외 거주 비율(UN)에서 피란분을 뺀 값을 나이 모양에 나눈 것 × 보정 배수.
- **피란:** 출생국에 사는 사람에게 나이와 관계없이 일어나는 사건 (고르는 일이 아님). 해외 거주자 중 피란민 비율(UNHCR)로 맞춘다.
- **목적지:** 그 나라 출신 이주자가 실제로 사는 곳의 비율에서 뽑는다 (UN 출신국×목적지 행렬).
- **이주 후:** 사는 나라가 바뀌어 생명표·소득분포·노동시장·사망 원인·결혼·출산이 모두 그 나라 기준이 된다. 첫 세대 이주자는 소득 순위가 낮게 시작한다.
- **귀국:** 해외에 사는 동안 해마다 귀국 갈림길이 올 수 있다.
- **측정 원칙:** 국가 통계는 그 나라에 사는 사람 기준이므로, 보정·감사·테스트는 출생국에 사는 동안만 센다. 해외에서 보낸 해는 해외 거주 비율 측정에만 쓴다.

## 7. 소득 모델

- 국가 소득분포는 로그정규분포로 근사: `σ = √2 · Φ⁻¹((Gini + 1) / 2)`, 평균은 1인당 GDP(PPP)에 노동소득 비율을 곱한 값.
- 개인의 **소득 백분위**는 출생 형편·학력·직업·경력·지식 상태값으로 정해지고, 금액은 그 백분위의 분위수로 환산한다.
- 표시 통화: PPP 달러 + "체감 원화"(한국 물가 기준 환산).
