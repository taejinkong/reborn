## 3단계 결과와 남은 과제

**완료**
- 시드 기반 결정적 엔진: 출생 추첨, 초점, 학교, 일·소득(지니 기반 로그정규), 가족, DSL 사건·갈림길, 생명표 사망
- 테스트 22개: 표현식, 난수, 오즈 정규화, 소득분포, 콘텐츠 린트, 출생 분포, 재현성, 이어하기, 문장 렌더링, 8개 국가·성별 기대수명 몬테카를로 검증(±2년)
- 엔진 데모(`apps/demo`)와 GitHub Pages 자동 배포

**수치 보정 (2026-10-23 완료)**
- 데이터 추가: UN World Marriage Data 2019(결혼 경험 비율·평균 초혼 연령), WPP 연령별 출산율
- `npm run calibrate`: 198개국 × 성별 1,500명 × 4회 반복 몬테카를로 보정 (약 4분, 10코어)
- 결과(보정에 쓰지 않은 시드로 검증): 기대수명 오차 평균 0.55년(90%가 1.0년 이내), 합계출산율 오차 평균 0.06, 45~49세 결혼 경험 오차 평균 1.0%p
- 보정 전 대비: 에티오피아 기대수명 −1.8년 → ±0.5년, 한국 결혼 경험 99% → 94%(통계 94%), 나이지리아 여성 출산 2.9명 → 4.5명(통계 4.3)
- 테스트 기준 강화: 10개 국가·성별에서 기대수명 ±1년, 결혼 경험 ±5%p, 합계출산율 ±10%

**빠진 모델 채우기 (2026-10-23 완료)**
- `npm run audit`: 대표 18개국의 시뮬레이션 결과를 실제 통계와 항목별로 비교해 [docs/model-audit.md](model-audit.md)로 저장
- 감사 결과에 따라 채운 모델 (모두 국가별 몬테카를로 보정):
  - 사망 원인: 임시 분포 → WHO GHE 2019 3대 분류 비중 + 교통사고·살인·자살·모성사망·HIV 국가 통계 (WDI, CC BY 4.0)
  - 노동: 경제활동 상태(참여/비참여) + 구직 → 15~64세 경제활동참가율·실업률 (ILO)
  - 흡연 시작·금연, 당뇨 발병 → 흡연율·당뇨 유병률
  - 이혼·재혼, 사별 → 45~49세 이혼·별거 비율 (UN World Marriage Data)
  - 조혼(12~17세, 아이가 고르는 일이 아니므로 사건으로 처리) → 조혼율 (UNICEF)
- 보정 결과 (198개국, 검증 시드): 기대수명 평균 0.54년, 합계출산율 0.06, 결혼 1.1%p, 조혼 0.9%p, 이혼 0.8%p, 경제활동 0.9%p, 실업 0.2%p, 흡연 1.0%p, 당뇨 0.4%p, 사망 원인 비중 1.0%p
- 감사 경고 대부분은 표본 잡음으로 확인 (6,000명 재검사 시 기대수명 ±0.15년 이내)

**국제 이주 모델 (2026-10-23 완료)**
- 데이터: UN International Migrant Stock 2024(출신국×목적지, CC BY 3.0 IGO), UNHCR 2024 국외 피란 인구
- 노동 이주(18~50세 갈림길), 피란(사건), 귀국(갈림길). 목적지는 실제 이주자 분포에서 추첨. 이주 후에는 그 나라의 통계로 산다
- 측정 원칙 정리: 국가 통계는 거주자 기준이므로 출생국에 사는 동안만 센다. 기대수명은 거주자 생명표(출생국에 사는 동안의 나이별 사망률)로 검증
- 결과 (198개국, 검증 시드): 해외 거주 비율 오차 평균 0.3%p(최대 1.8%p). 피란민 비율·1위 목적지 비율은 대표 국가 감사에서 확인 (사우디·나이지리아처럼 이주가 드문 나라는 대규모 표본으로 재확인: 목적지 비율 ±3%p)
- 기존 항목 유지: 기대수명 평균 0.57년, 노동 1.2%p, 출산 0.06 등

**알려진 한계**
- 걸프 국가 남성 경제활동참가율이 5~9%p 낮게 나옴: 국가 통계는 이주 노동자가 많은 단면 인구 기준, 시뮬레이션은 한 사람의 일생 기준. 이주 모델로 다른 나라 사람이 걸프로 일하러 가는 삶은 생겼지만, 걸프 출생자의 통계와는 여전히 비교 기준이 다름
- 이집트 조혼율 약 5%p 높음 (평균 초혼 연령이 낮은 나라에서 18세 전후 결혼 분포의 한계)
- 대학 진학은 고등교육 총취학률과 정의가 달라 참고용 (한국·중국 등에서 낮게 나옴)
- 사망 원인 세부 연령 패턴, 결혼·이혼 기간 모양, 경제활동 전환율은 추정값 ([data/SOURCES.md](../data/SOURCES.md))
- 팔레스타인 난민 대부분(UNRWA 소관)은 피란민 비율에 빠져 있음
- UNHCR 데이터 이용 약관 원문은 출시 전 확인 필요
- 해외에서 다른 나라로 다시 옮기는 2차 이주, 가족 일부만 떠나는 이주는 아직 없음
- 동반자 없는 출산은 아직 없음 (출산 보정 계수가 평균적으로 흡수)
- 보정은 자동 결정 모드의 선택 경향 기준. 콘텐츠를 바꾸면 `npm run calibrate`로 다시 보정해야 함
- 이름, 지역 문화, 이주, 동시 출생자 4명은 아직 없음

## 4단계 결과 (2026-10-24)

**완료**
- `apps/web`: Next.js 15 정적 내보내기 + Tailwind 4, GitHub Pages `/reborn/` 배포 (엔진 데모는 `/reborn/demo/`)
- 화면: 첫 화면(실시간 출생·사망 카운터, 태어날 확률 상위 10개국, 설정) → 출생 추첨 연출 → 출생 신고서(실제 출생국 비교) → 인생 화면 → 갈림길 → 사망 기록 → 전생 기록
- 인생 화면: 상태값, 신상, 장면 그림(임시 SVG), 올해의 초점, 인생 기록, 인생 지도(한 칸 = 1년), 생존 곡선, 사는 나라 통계
- 진행: 1~16배속, 멈춤(스페이스바), 다음 갈림길까지, 자동 결정, 해마다 자동 저장·이어하기
- 사망 기록: 기대수명·동갑 생존자와 비교, 행복·건강 변화, 인생 지도, 기록, 공유 이미지(1080×1350)
- 국가 통계: 198개 국가·지역 정적 페이지 (지표별 값·기준 연도·출처·추정 표시, 이주 목적지)
- 무거운 장면 숨기기(민감한 기록의 문장을 가림), 밝은/어두운 모드, 키보드 포커스, 동작 줄이기 설정 존중
- PWA: 매니페스트, 서비스 워커(데이터·정적 파일 캐시)

**남은 과제**
- 실제 휴대폰 화면 점검 (반응형 클래스는 적용했지만 브라우저 창 크기 조절로 확인하지 못함)
- 이름 (출생 신고서에 이름이 없음 — 문화권별 이름 풀 필요)
- 장면 그림을 생성형 이미지로 교체 (7단계), 연간 서사 AI (6단계)
- 홈 화면용 PNG 아이콘 (지금은 SVG만), 소개·개인정보 처리방침 페이지
- 동시 출생자 4명, 시대 모드 (v1)

## 저장소 구조

```
reborn/
  apps/demo/           # 엔진 데모 (Vite) — /reborn/demo/
  apps/web/            # Next.js PWA (GitHub Pages /reborn/)
  packages/engine/     # 시뮬레이션 엔진 + DSL 스키마·린터 (순수 TS)
  content/             # YAML 콘텐츠 (사건·갈림길·초점·직업·문장)
  scripts/             # 콘텐츠 빌드
  pipeline/            # 데이터 수집·가공 (Python)
  data/build/          # 엔진 입력 JSON
  docs/                # 기획 문서
```
